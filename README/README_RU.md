## 📖 О проекте

AVIV объединяет воспроизведение белого шума, локальную/онлайн-музыку и профессиональный движок обработки звука в реальном времени. Все эффекты рассчитываются в реальном времени на уровне C++ поверх низколатентных аудиопотоков Oboe — без предварительного рендеринга, изменения параметров применяются мгновенно. Подходит для помощи сну, концентрации, медитации, создания атмосферы и улучшения музыки.

> ⚠️ **Примечание:** при первом запуске сбор логов включён по умолчанию (для сбора логов сбоев); его можно отключить в Настройках.

## ✨ Возможности

### 🌊 Белый шум
- Несколько встроенных источников, organised по категориям, локальные и онлайн
- **Scatter-режим**: случайное воспроизведение с настраиваемым интервалом и диапазоном, имитация естественного звукового поля
- **Независимая цепочка эффектов** наeachдый трек (EQ / реверб / пространственный / креативные), без взаимных помех
- Диапазон усиления громкости 0–300%

### 🎵 Воспроизведение музыки
- Мультиформатная поддержка (MP3 / WAV / FLAC / AAC и др.)
- Управление плейлистами
- Онлайн-стриминг на базе **скриптового движка источников QuickJS**, автоопределение нескольких движков и автоматическое переключение при тайм-ауте

### 🎛️ Эффекты реального времени (движок C++)
| Эффект | Описание |
|------|------|
| **Эквалайзер (EQ)** | Ручные многополосные BiQuad-фильтры, независимые кривые на трек, с Bypass |
| **AutoEQ компенсация динамиков** | 12 пресетов устройств, 16 настраиваемых параметров, все параметры фильтров (усиление/частота/Q) редактируются по полосам и сохраняются |
| **Пространственное аудио** | 3D-позиционирование источника, затухание по расстоянию, траектория окружения (0,25–10 с/оборот), случайное рассеяние, фиксированное смещение |
| **Реверб** | Размер комнаты, время затухания, предзадержка, wet/dry микс, изоляция |
| **Лимитер** | Brick-wall ограничение, кривая передаточной функции + VU-метр + метр GR, визуализация в реальном времени |
| **Креативные эффекты** | Lo-Fi / 8-bit / Подводный / Чужой сигнал / Мегафон / Дисторшн |
| **Псевдо-восстановление** | HiFi-улучшение (мягкое колено перехода, DC-блок, сглаживание усиления) |
| **Многополосный компрессор** | MultibandCompressor |
| **Стерео-расширитель / Виртуальный бас / Изоляция** | StereoWidener / VirtualBass / Insulation |
| **Темп & высота тона** | На базе **SoundTouch**, темп 0,1–5,0×, высота ±12 полутонов, независимая настройка |

### 🎛️ Панель микшера
- Единая точка управления эффектами: интенсивность, EQ, AutoEQ, пространственное аудио, реверб, лимитер, темп/высота
- Предпросмотр в реальном времени, мгновенное применение параметров
- Сброс одним нажатием

### ⏰ Таймер
- Таймер сна (до 23 ч 59 м)
- Режим повтора
- Нажмите шар таймера, чтобы начать отсчёт

### 🐾 Плавающий питомец
- Плавающий питомец на рабочем столе, перетаскиваемый / масштабируемый / скрываемый
- Масштабирование с привязкой к центру, пробуждение из скрытого состояния

### 🎨 Персонализация
- **Кастомные темы**: HSV-настройка цвета + пресеты тем
- **Эффекты матового / жидкого стекла**
- Автосохранение параметров эффектов

### 🔔 Система уведомлений
- **Внутриприложении уведомления**: 5 типов (Инфо/Успех/Предупреждение/Ошибка/Загрузка), уровни приоритета, свайп для закрытия, кнопки действий
- **Системные медиа-уведомления**: интеграция MediaSession, управление с экрана блокировки

### 🛡️ Стабильность и удержание
- **Поддержка аудиопотока**: стратегия AudioFocus, отказоустойчивый повтор при разрыве потока, оптимизация буфера, корректное восстановление ошибок Oboe, резерв MediaPlayer
- **Руководство по удержанию в фоне**: белый список оптимизации батареи + руководство по настройкам автозапуска производителей
- **Диагностика блокировки памяти**: мониторинг исключений (перезапуск аудиодвижка / недозагрузка буфера / задержки главного потока / предупреждения о памяти) + диагностические отчёты
- **Система логов**: отдельный процесс для захвата Logcat и логов сбоев

### 🌍 Мультиязычность
Поддержка 10 языков: китайский, английский, японский, корейский, русский, французский, немецкий, испанский, итальянский, португальский

## 🔊 Аудиодвижок

### Конвейер обработки

```
Декодер ──► Громкость/Затухание ──► Изоляция ──► Пространственное аудио ──► Реверб
        ──► EQ / AutoEQ ──► Креативные ──► Псевдо-восстановление ──► Лимитер
        ──► SoundTouch(Темп/Высота) ──► Жёсткий клиппинг ──► Вывод Oboe
```

### Структура модулей C++

| Каталог | Ответственность |
|------|------|
| `cpp/AudioPlayFunc/` | `AudioEngine` (управление потоками Oboe, микширование многоканальности), `AudioTrack` (декодирование и цепочка эффектов на трек) |
| `cpp/AudioEffect/` | 12 процессоров эффектов + `AudioEffectManager` + `SoundTouchProcessor` |
| `cpp/equalizer/` | Реализация BiQuad-фильтров |
| `cpp/reverb/` | Алгоритм реверба |
| `cpp/spatial_audio/` | HRTF пространственного аудио |
| `cpp/oboe/` | Библиотека Google Oboe низколатентного аудио |
| `cpp/ffmpeg/` | Декодирование FFmpeg (LGPL) |

### JNI-интерфейс
`JniInterface.cpp` открывает все аудиовозможности (управление воспроизведением, параметры эффектов, кривые EQ, пространственное аудио, AutoEQ, лимитер, темп/высота SoundTouch и др.); сторона Kotlin обёрнута в `OboeAudioEngine`.

## 🏗️ Архитектура

| Слой | Технология |
|----|------|
| UI | Kotlin + Jetpack Compose + Material 3 |
| Аудио | C++ + Oboe + SoundTouch + FFmpeg (JNI) |
| Сеть | OkHttp |

### Основные пакеты Kotlin

## 📥 Загрузка и установка

### Системные требования
- Android 7.0 (API 24) или выше
- Не менее 100 МБ свободного хранилища

### Установка
1. Скачайте последний APK из [Releases](https://github.com/byxixiaoshao/AVIV/releases)
2. Включите «Установка неизвестных приложений» на устройстве
3. Откройте APK для установки
4. Запустите приложение

## 🔧 Сборка из исходников

### Требования
- Android Studio (поддержка текущей версии AGP)
- JDK 11
- Android SDK, compileSdk 36
- NDK 27.0.12077973, CMake 4.3.0
- Поддерживаемые ABI: `arm64-v8a`, `armeabi-v7a`

### Шаги
```bash
git clone <url-репозитория>
cd AVIV/Android
./gradlew :app:assembleRelease
```

> Для сборки требуется конфигурация подписи `keystore.properties`. Исходники SoundTouch находятся в корневом каталоге проекта `soundtouch/` и компилируются CMake в статическую библиотеку автоматически.

## 📖 Руководство

### Белый шум
1. На главном экране выберите категорию и источник белого шума
2. Нажмите карточку источника для запуска воспроизведения
3. Долгое нажатие на карточку для настройки независимых эффектов
4. Scatter-режим: случайное воспроизведение нескольких источников

### Музыка
1. Свайп вниз по верхней панели воспроизведения для входа в плеер
2. Добавьте музыку через выбор файлов
3. Настройте эффекты в панели микшера

### Настройка эффектов
Откройте **панель микшера**:
- **Эквалайзер** → Equalizer Panel
- **Компенсация AutoEQ** → Speaker Compensation (редактирование по полосам)
- **Пространственное аудио** → Spatial Audio Panel
- **Реверб** → Reverb Panel
- **Лимитер** → Limiter (с визуализацией передаточной функции)
- **Темп/высота** → Настройка скорости (SoundTouch)
